# 分诊标签

各技能以五种规范分诊角色来表述。本文件把这些角色映射为本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本跟踪器中的标签 | 含义 |
| -------------------------- | ---------------- | ---- |
| `needs-triage`             | `needs-triage`   | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`     | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`| 已完全明确，可由 AFK 代理执行 |
| `ready-for-human`          | `ready-for-human`| 需要人工实现 |
| `wontfix`                  | `wontfix`        | 不予处理 |

当某个技能提到某个角色时（例如「打上 AFK 就绪的分诊标签」），请使用本表中对应的标签字符串。

请按你实际使用的词汇修改右列。
